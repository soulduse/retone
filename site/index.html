FAQ

자주 묻는 질문

무료 버전과 Cloud의 차이가 뭔가요?

기능은 같습니다. 무료(셀프호스팅)는 내 컴퓨터에 작은 헬퍼 프로그램을 설치하고 내 AI 구독(Claude Code·Codex 등)이나 API 키로 동작합니다. Cloud는 그 설치 과정 없이 Retone 서버가 대신 다듬어 주는 편의 옵션입니다.

헬퍼 설치가 어렵지 않나요?

Node.js가 있다면 터미널에 npm install -g retone && retone install 한 줄이면 끝나고, 이후엔 컴퓨터를 켤 때 자동으로 실행됩니다. 터미널이 낯설다면 Cloud를 쓰시면 됩니다.

제 글이 학습에 쓰이거나 저장되나요?

아니요. Retone은 초안과 결과를 저장하지 않으며, 무료 버전에서는 글이 서버를 거치지도 않습니다. AI 제공사(Anthropic·OpenAI·Google)의 처리에는 각 사의 약관이 적용됩니다.

환불 규정은 어떻게 되나요?

Cloud 구독은 결제 후 14일 이내 요청 시 사유를 묻지 않고 전액 환불합니다. 자세한 내용은 환불정책을 참고하세요.

어떤 플랫폼을 지원하나요?

현재 x.com(트위터)과 threads.com의 게시글·답글 작성창을 지원합니다. LinkedIn 등 다른 플랫폼은 로드맵에 있습니다.
