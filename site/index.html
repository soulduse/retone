FAQ

자주 묻는 질문

무료 버전과 Cloud의 차이가 뭔가요?

다듬는 기능은 같고, 누가 AI를 돌리느냐가 다릅니다. Cloud는 Retone 서버가 처리하므로 확장을 켜는 즉시 쓸 수 있고 하루 100회·월 3,000회까지 이용합니다. 셀프호스팅은 내 컴퓨터에 헬퍼를 설치하고 내 AI 구독이나 API 키로 직접 돌리는 방식이라, 설치와 관리를 스스로 하는 대신 사용량 제한이 없습니다.

헬퍼 설치가 어렵지 않나요?

Node.js가 있다면 터미널에 npm install -g retone && retone install 한 줄이면 끝나고, 이후엔 컴퓨터를 켤 때 자동으로 실행됩니다. 설치 자체를 건너뛰고 싶다면 Cloud를 쓰시면 됩니다.

제 글이 학습에 쓰이거나 저장되나요?

아니요. Retone은 초안과 결과를 데이터베이스에도 로그에도 남기지 않고, 학습에 쓰지 않습니다. 셀프호스팅에서는 글이 Retone 서버를 거치지도 않습니다. AI 제공사(Anthropic·OpenAI·Google)의 처리에는 각 사의 약관이 적용됩니다.

환불 규정은 어떻게 되나요?

Cloud 구독은 결제 후 14일 이내 요청 시 사유를 묻지 않고 전액 환불합니다. 해지도 결제 확인 메일의 링크에서 언제든 직접 할 수 있고, 해지해도 남은 기간까지는 그대로 이용됩니다. 자세한 내용은 환불정책을 참고하세요.

하루 100회·월 3,000회면 충분한가요?

하루에 글 몇 개를 쓰고 톤을 여러 개 받아봐도 넉넉한 양입니다. 한 번 다듬을 때 고른 톤이 3개든 5개든 1회로 계산합니다. 남은 횟수는 확장 설정 화면에서 언제든 확인할 수 있고, 한도에 닿아도 다음 날(또는 다음 달)에 다시 채워집니다.

결제하면 바로 쓸 수 있나요?

네. 결제 후 확장이 자동으로 구독을 인식합니다. Google 계정으로 연결해 두면 다른 기기에서도 로그인만으로 그대로 이어서 쓸 수 있고, 연결하지 않았다면 결제에 사용한 이메일로 보내드린 라이선스 키를 설정에 넣으면 됩니다.

어떤 플랫폼을 지원하나요?

현재 x.com(트위터)과 threads.com의 게시글·답글 작성창을 지원합니다. LinkedIn 등 다른 플랫폼은 로드맵에 있습니다.
