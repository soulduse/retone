판매 상품 안내

Retone은 X(트위터)·Threads 작성창에서 초안을 여러 어조로 다듬어 주는 Chrome 확장 프로그램입니다. 아래는 유료로 제공되는 Retone Cloud 상품이며, 모두 실물 배송이 없는 디지털 서비스입니다. 결제 즉시 라이선스 키가 이메일로 발급되어 바로 이용할 수 있습니다.

구독 · 월간

Retone Cloud 월간 구독

$4.99 / 월 (세금 별도)

헬퍼 프로그램 설치 없이, Retone 서버가 대신 글을 다듬어 주는 구독 상품입니다. Chrome 확장에 라이선스 키를 입력하면 즉시 활성화됩니다.

  • 제공 기간 — 결제일로부터 1개월, 해지 전까지 매월 자동 갱신
  • 이용 한도 — 하루 100회, 월 3,000회 다듬기 (공정 이용 한도)
  • 제공 기능 — 어조 프리셋 7종 + 사용자 정의 프리셋, 다중 어조 동시 생성, 작성창 자동 삽입
  • 지원 환경 — Chrome 브라우저(버전 116 이상), x.com·threads.com
  • 제공 방식 — 결제 완료 후 이메일로 라이선스 키 발급 (즉시 이용 가능)
  • 배송 — 해당 없음 (온라인 디지털 서비스)

무료

셀프호스팅 (오픈소스)

무료 · 결제 없음

Chrome 확장과 로컬 헬퍼를 직접 설치해, 본인이 이미 사용 중인 AI 구독이나 API 키로 이용하는 방식입니다. 결제가 발생하지 않으며 기능 제한도 없습니다.

  • 제공 방식 — MIT 라이선스 오픈소스 (GitHub 공개)
  • 필요 조건 — Node.js 18 이상, 본인의 AI 구독 또는 API 키
  • 이용 한도 — 별도 제한 없음 (선택한 AI 제공사의 정책에 따름)

결제 및 환불 안내

결제 방법

신용카드·체크카드 결제를 지원하며, 구독 상품은 최초 결제 시 등록한 카드로 결제 주기마다 자동 결제됩니다. 결제는 전자결제대행사(PG)를 통해 안전하게 처리되며, 카드 정보는 Retone 서버에 저장되지 않습니다.

이용 개시 시점

결제 완료 즉시 라이선스 키가 이메일로 발송되며, Chrome 확장 설정 화면에 키를 입력하면 바로 이용할 수 있습니다. 별도의 배송 절차는 없습니다.

환불 정책

  • 14일 무조건 환불 — 최초 결제일로부터 14일 이내에는 사유를 묻지 않고 전액 환불해 드립니다.
  • 14일 경과 후 — 서비스 장애 등 회사의 귀책 사유가 있는 경우 남은 기간을 일할 계산하여 환불합니다.
  • 연간 구독 중도 해지 — 14일 이내는 전액 환불, 이후에는 이용한 개월 수를 월간 요금으로 환산·공제한 잔액을 환불합니다.
  • 환불 요청 방법 — corp@infinityapps.info로 주문번호 또는 라이선스 키와 함께 요청해 주세요. 영업일 기준 3일 이내에 처리됩니다.

구독 해지

언제든 해지할 수 있으며, 해지 시 이미 결제된 기간이 끝날 때까지 정상적으로 이용할 수 있습니다. 해지 요청은 위 이메일로 접수됩니다.
